# 17　结语：十一条结论、一张速查表、一条路线

推导读完之后，真正能带走的是少数几条结构性认识。这一章把它们压缩，方便你日后回查。

## 17.1　十一条结论

1. **损失函数不是设计出来的，是假设出来的。** 选 MSE 就假设了高斯噪声，选交叉熵就假设了类别分布。改了数据分布却还用原来的损失，模型一定学偏。
2. **反向传播 = 记图 + 倒着走链式法则。** 框架不推导公式，它只是按每个算子的固定规则回传。理解这一点，梯度问题的排查就有章法。
3. **条件数决定训练难度。** 学习率、动量、归一化都在做同一件事：拉平各方向的曲率。
4. **梯度消失/爆炸是连乘问题。** RNN 里是权重矩阵的谱半径，深层网络里是激活导数与权重的乘积。残差与门控之所以有效，是因为它们给梯度开了一条系数接近 1 的路径。
5. **注意力是"按相似度加权检索"。** 除以 $\sqrt{d}$ 是方差归一化，多头是并行多个子空间，位置编码是补上置换等变性丢掉的顺序。
6. **生成模型的分歧在"如何近似不可解的高维密度"。** VAE 用变分下界，GAN 用对抗估计，扩散用逐步去噪。越接近"把困难任务拆成简单任务"的方案，训练越稳。
7. **正则化 = 先验 = 控制有效容量。** 它不是补丁，是把"我认为参数应该长什么样"写进目标函数。
8. **偏差-方差只能权衡，不能同时消掉。** 容量、数据量、噪声水平三者的比例决定了你在曲线的哪一侧。
9. **采样与估计都有 $1/\sqrt{N}$ 的噪声。** batch 加大 4 倍，噪声只减半；测试集差 0.5% 时，别急着下结论。
10. **inductive bias 决定了数据效率。** CNN 的平移等变让它在小数据上远超 MLP；ViT 用海量数据把这个偏置换回来。没有绝对更好的结构，只有匹配数据的结构。
11. **工程上能算的账，比能讲的道理更重要。** 显存、延迟、吞吐、成本——卷三整卷都在算这些。

## 17.2　公式速查表

| 场景 | 公式 | 备注 |
| --- | --- | --- |
| 线性层反向 | $\mathrm{d}X=\mathrm{d}YW$，$\mathrm{d}W=\mathrm{d}Y^\top X$ | 形状对齐即可自检 |
| Softmax + CE | $\partial L/\partial z=p-y$ | 数值稳定，勿拆开算 |
| 逻辑回归 | $\nabla_w L=X^\top(p-y)$ | 凸，但无闭式解 |
| 最小二乘 | $\hat w=(X^\top X)^{-1}X^\top y$ | 共线时改用岭回归 |
| 岭回归 | $\hat w=(X^\top X+\lambda I)^{-1}X^\top y$ | 条件数从 $\infty$ 变有限 |
| SGD 收敛条件 | $0<\eta<2/\lambda_{\max}$ | 二次函数情形 |
| Adam | $\theta\leftarrow\theta-\eta\hat m/(\sqrt{\hat v}+\epsilon)$ | 偏差修正是关键 |
| 注意力 | $\mathrm{softmax}(QK^\top/\sqrt{d})V$ | 复杂度 $O(T^2d)$ |
| ELBO | $\mathbb{E}_q[\log p(x\mid z)]-D_{\mathrm{KL}}(q\|p(z))$ | VAE 训练目标 |
| 扩散前向 | $x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$ | 一步到位，无需迭代 |
| 策略梯度 | $\mathbb{E}[\nabla\log\pi_\theta(a\mid s)A]$ | 减基线降方差 |
| PPO | $\min(rA,\mathrm{clip}(r,1\pm\epsilon)A)$ | 限制单步更新幅度 |

## 17.3　如果只能记住一件事

> 把每个模型看成"一个假设 + 一个目标函数 + 一个优化过程"。假设决定它能表示什么，目标决定它往哪走，优化决定它走不走得到。

这三件事里，**出问题最多的是第二件和第三件，但人们最常怀疑第一件**。模型效果不好时，先看损失和数据，再看优化，最后才动结构。
