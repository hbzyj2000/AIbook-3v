# 16　概率图模型：把依赖关系画出来

第 3 章讲了概率的基础。这一章讲**如何用图结构表达多变量的联合分布**，以及为什么它曾经是 AI 的主流范式。

## 16.1 两种图、两种语义

| 类型 | 边表示 | 联合分布 |
| --- | --- | --- |
| 有向图（贝叶斯网） | 条件依赖 | $\prod_i p(x_i\mid \mathrm{pa}(x_i))$ |
| 无向图（马尔可夫随机场） | 相互影响 | $\frac{1}{Z}\prod_c \psi_c(x_c)$ |

有向图的分解极其简洁：**每个变量只依赖它的父节点**。这把高维联合分布拆成一堆局部条件概率，参数量从指数级降到线性级。

## 16.2 三个经典结构

```text
链式   A → B → C        p(A,B,C)=p(A)p(B|A)p(C|B)
分叉   A ← B → C        给定 B，A 与 C 独立
对撞   A → B ← C        给定 B，A 与 C 反而相关（解释消除）
```

**对撞结构是理解"条件独立"的关键**：两个原因在结果上"撞"到一起，一旦你知道了结果，两个原因就开始互相解释。这解释了为什么"控制变量"有时会引入伪相关（Berkson 悖论）。

## 16.3 推断：三种难度

| 任务 | 问什么 | 难度 |
| --- | --- | --- |
| 边缘化 | $p(x_i)$ | 一般图上是 NP-hard |
| 条件概率 | $p(x_i\mid e)$ | 同上 |
| MAP | $\arg\max_x p(x\mid e)$ | 同上 |

精确推断只在树状结构上高效（信念传播）。一般图用近似：

- **变分推断**：用一个简单分布 $q$ 逼近后验，最小化 $D_{\mathrm{KL}}(q\|p)$；
- **采样（MCMC/Gibbs）**：从后验采样，样本多了近似分布；
- **Loopy BP**：在含环的图上强行做信念传播，不保证收敛但常有好效果。

变分推断的核心式子（ELBO）：

$$ \log p(x)\ge \mathbb{E}_{q(z)}\log p(x,z)-\mathbb{E}_{q(z)}\log q(z) $$

这个下界就是 VAE 的目标函数来源（第 13 章）。**它把"难算的边缘似然"变成"可优化的下界"**，是概率图与深度学习最重要的接口。

## 16.4 隐变量模型：为什么需要它

很多数据表面上简单，背后有未观测的原因。隐变量模型显式地建模这些原因：

| 模型 | 隐变量 | 用途 |
| --- | --- | --- |
| 高斯混合（GMM） | 每个样本属于哪个簇 | 聚类 |
| HMM | 每时刻的隐状态 | 语音识别、序列标注 |
| LDA | 文档的主题分布 | 主题发现 |
| VAE | 潜向量 | 生成 |

EM 算法是训练这类模型的标准方法（第 3 章讲过）。它的两步：

$$ \text{E 步：}Q(z)=\ p(z\mid x,\theta_{\text{old}}),\qquad \text{M 步：}\theta_{\text{new}}=\arg\max_\theta\mathbb{E}_Q\log p(x,z\mid\theta) $$

**EM 保证似然单调不减**，这是它比直接梯度下降更可靠的地方。

## 16.5 概率图与深度学习的关系

深度模型看起来与图模型无关，其实有很多交集：

| 交集 | 体现 |
| --- | --- |
| 目标函数 | 交叉熵、ELBO、对比损失都有概率解释 |
| 结构先验 | 注意力掩码就是一种条件独立结构 |
| 生成模型 | VAE、扩散都是隐变量模型 |
| 不确定性 | 贝叶斯神经网络、MC Dropout |

统计学家常说的一句话：**深度学习是"用参数化函数替代了图结构"**。真正的取舍是：图结构提供强先验但表达能力受限，神经网络表达能力强但需要大量数据。数据少时前者更好，数据多时后者更好。

## 16.6 什么时候还该用图模型

- 变量数少、依赖关系明确（如医疗诊断、故障定位）；
- 需要**可解释的因果路径**（"因为 A 所以 B"）；
- 数据量小但结构先验强；
- 需要严格的不确定性量化。

这些场景里，图模型仍然比深度网络更合适。**它不是过时的方法，而是不同假设下的不同工具。**

:::note 要点
概率图模型最大的价值不是某个具体算法，而是**"条件独立"这个概念**。它让你能判断：加了某个特征会不会引入伪相关、控制某个变量会不会造成对撞偏差。这个判断力在任何模型上都适用。
:::
