# 0　导读：这本教程怎么用

你可能已经有过这样的体验：看过很多讲 AI 的文章，知道"梯度下降""注意力机制""反向传播"这些词，但一旦有人问"为什么是这个公式"，就只能重复别人的比喻。工程背景的人学 AI 有一个天然优势和一个天然陷阱。优势是你能把抽象结构想象成数据流和内存布局；陷阱是你容易满足于"跑通就行"，于是模型一改结构就不知道从哪调。

这一卷的写法是：**每个公式先交代它要求解的问题，再给推导，最后说明它在工程里的形状**——哪一维是 batch，哪一维是特征，什么时候会炸，什么时候可以近似。

## 0.1　三卷怎么分工

三卷不是三个难度层级，而是三种进入同一个领域的视角。你可以按需交叉读。

| 卷 | 视角 | 适合什么时候读 | 读完能得到什么 |
| --- | --- | --- | --- |
| 卷一 | 原理与推导 | 想把"为什么"弄明白 | 能自己推一遍反向传播、注意力、ELBO |
| 卷二 | 全景与取舍 | 想建立完整地图、做技术选型 | 知道每个方法解决什么问题、代价是什么 |
| 卷三 | 工程与落地 | 要把模型真正跑起来 | 会算显存、会调推理、会搭 RAG 与 Agent |

三卷共享同一套符号与术语。卷一只讲必要的东西，不讲工程细节；卷三只讲工程，公式直接引用卷一的结论。

## 0.2　你需要补的三块数学

你的课表里，微积分、线性代数、概率、离散数学、信号与系统、数字图像处理都在。这已经覆盖了 AI 所需的绝大部分工具，问题通常出在三个"衔接处"：

1. **矩阵求导**。高数讲的是标量对向量，AI 里天天是向量对向量、标量对矩阵。这一块不是新数学，只是把链式法则写成矩阵形式，第 5、6 章会补。
2. **概率的工程用法**。你学过概率分布，但可能没做过"用最大似然推出交叉熵损失"这种事——而深度学习的几乎每个损失函数都是某个分布假设下的最大似然。第 3、4 章专门接这个口。
3. **最优化直觉**。会求导不等于会训模型。学习率、条件数、病态、鞍点这些词，本质是数值分析问题，第 5 章和第 11 章会把它们讲成"你能看见的几何"。

:::note 建议的补课顺序
不要先去啃一本《矩阵分析》。按需补：读到反向传播时补矩阵求导，读到交叉熵时补 KL 散度，读到 Adam 时补指数滑动平均。缺口在哪补哪，比先修三门课快得多。
:::

## 0.3　符号约定

全书统一这套记号，看到就先对上号，不要被不同教材的不同写法带偏。

| 记号 | 含义 | 典型形状 |
| --- | --- | --- |
| $x$ | 一个样本的输入向量 | $\mathbb{R}^{d}$ |
| $X$ | 一个 batch 的输入矩阵 | $\mathbb{R}^{B\times d}$ |
| $W$ | 权重矩阵 | $\mathbb{R}^{d_{in}\times d_{out}}$ |
| $\theta$ | 全部可学习参数的集合 | 若干张量 |
| $L$ 或 $\mathcal{L}$ | 损失（标量） | $\mathbb{R}$ |
| $\nabla_\theta L$ | 损失对参数的梯度 | 与 $\theta$ 同形状 |
| $\odot$ | 逐元素乘 | 同形状 |
| $\|\cdot\|_2$ | L2 范数 | 标量 |
| $\mathbb{E}_{p}[f]$ | 在分布 $p$ 下取期望 | 标量 |
| $\sigma(\cdot)$ | Sigmoid 函数 | 逐元素 |

约定两条，能省掉大量混乱：

- **batch 维永远在最前面**。所以一个线性层写 $Y = XW + b$，$X$ 是 $B\times d_{in}$，$Y$ 是 $B\times d_{out}$。看到公式里 $W$ 在左边（$WX$），多半是教材用列向量约定，不代表错，只是转置关系。
- **下标表示"哪一维"，不表示"第几个样本"**。$x_i$ 是向量的第 $i$ 个分量；第 $n$ 个样本写 $x^{(n)}$。

## 0.4　每章的结构

每一章都按同一个节奏展开，你读几章就会发现规律：

1. 开头一句摘要，说明这章解决什么问题；
2. 正文先给"问题—方法—代价"，再给推导；
3. `要点` 块收拢必须记住的结论；
4. `常见坑` 块写实际会踩的错，多数来自工程而非数学；
5. `工程视角` 块把它翻译成代码里的形状与数值行为；
6. 章末练习题，难度大约是需要动笔 10 到 30 分钟。

页面里嵌了几个实验台，比如梯度下降、Softmax 温度、卷积滑窗、注意力热图。它们不是装饰——**把参数推到极端再推回来，你对公式的直觉会比读十遍定义更牢**。

## 0.5　工具链：从 C++ 工程师的角度

你不必先学 Python 才能理解 AI，但**动手跑一遍是理解的一部分**。最小可用环境：

```cpp
// 如果你只想验证数学，C++ 就够了：手写一个两层 MLP 的反向传播
// 下面这段是"一个线性层 + ReLU + MSE"的前向与反向骨架
struct Linear {
    std::vector<float> W;   // out_dim * in_dim，行主序
    std::vector<float> b;   // out_dim
    int in_dim, out_dim;
};

// y = x W^T + b，x 是 batch×in_dim
void forward(const Linear& l, const float* x, int B, float* y) {
    for (int n = 0; n < B; ++n)
        for (int o = 0; o < l.out_dim; ++o) {
            float s = l.b[o];
            for (int i = 0; i < l.in_dim; ++i)
                s += x[n * l.in_dim + i] * l.W[o * l.in_dim + i];
            y[n * l.out_dim + o] = s;
        }
}
// 反向：dW += dy^T x, db += sum_n dy, dx = dy W
```

真正做实验时，用 PyTorch 更省时间；但上面这段能让你清楚"自动微分到底在存什么"。第 6 章会把自动微分的两种模式讲透，那时你会明白：**框架替你做的事，本质是记住前向的计算图，然后从输出往回走一遍链式法则**。

:::eng 工程视角
判断自己是否真的懂了某章，有个很硬的标准：能不能不看资料，写出这个操作的形状变换和张量下标。不能，就回去补；能，就往下走。AI 的门槛不在数学深度，而在"能把符号翻译成数组"。
:::

## 0.6　阅读路径建议

按你的背景，推荐这样走：

- **第一遍（约两周）**：第 2、3、5、6、7、11、13 章。这七章是主干，覆盖从线性模型到 Transformer 的必要链条。跳过第 8、9、10 章的细节，只读摘要。
- **第二遍（约三周）**：回头补 8、9、10、12 章，把传统方法和卷积、序列模型补齐；同时做章末练习。
- **第三遍（按需）**：14、15 章生成模型与强化学习。这两块数学密度最高，建议在需要时读，不必一次啃完。

如果你更想先建立地图再决定钻哪里，可以先读卷二，再回来按图索骥。这不是偷懒——**先知道有哪些工具，再学怎么造工具，对工程师往往更高效**。
