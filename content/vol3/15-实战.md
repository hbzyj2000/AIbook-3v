# 14　实战：搭一个可用的本地 RAG 系统

这一章把前面的东西串起来，做一条**最小但完整**的链路。目标不是"最好的系统"，而是"每一环都能独立调试、独立评估"。

## 14.1 技术选型（最小依赖）

| 环节 | 选择 | 理由 |
| --- | --- | --- |
| 解析 | `pypdf` + 手工表格处理 | 零成本，够用 |
| 切分 | 自己写（按标题/长度） | 好调、可解释 |
| 嵌入 | `bge-small-zh`（sentence-transformers） | CPU 可跑，中文好 |
| 索引 | numpy 矩阵 + 暴力检索 | 万级文档足够，免装向量库 |
| 关键词 | `rank_bm25` | 补专有名词召回 |
| 生成 | llama.cpp server（本地）或 API | 二选一，接口一致 |

**先用 numpy 暴力检索**是刻意的选择：一万个块、384 维，一次检索是 4M 次乘加，毫秒级。装向量库在这规模下只是增加复杂度。

## 14.2 第 1 步：解析与切分

```python
from pypdf import PdfReader

def load_pages(pdf_path):
    pages = []
    for i, page in enumerate(PdfReader(pdf_path).pages):
        t = (page.extract_text() or "").strip()
        if len(t) > 20:                       # 过滤空白页/封面
            pages.append({"page": i + 1, "text": t})
    return pages

def chunk(pages, max_chars=400, overlap=80):
    out = []
    for p in pages:
        t = p["text"]
        for i in range(0, len(t), max_chars - overlap):
            piece = t[i:i + max_chars]
            if len(piece) < 30:
                continue
            out.append({"text": f"第{p['page']}页：{piece}",
                        "page": p["page"], "src": "doc.pdf"})
    return out
```

**两个细节**：前缀里带页码（让模型能引用），以及过滤过短的块（避免噪声）。

## 14.3 第 2 步：建索引

```python
import numpy as np, pickle
from sentence_transformers import SentenceTransformer

enc = SentenceTransformer("BAAI/bge-small-zh-v1.5")

def build_index(chunks):
    vecs = enc.encode([c["text"] for c in chunks],
                      normalize_embeddings=True, batch_size=32)
    vecs = np.asarray(vecs, dtype="float32")       # (N, 384)
    with open("index.pkl", "wb") as f:
        pickle.dump({"chunks": chunks, "vecs": vecs}, f)
```

`normalize_embeddings=True` 之后，余弦相似度就等于内积，检索时直接 `vecs @ q`。

## 14.4 第 3 步：混合检索 + 重排

```python
from rank_bm25 import BM25Okapi

def tokenize_zh(s):                       # 中文用字级简单切
    return list(s)

bm25 = BM25Okapi([tokenize_zh(c["text"]) for c in chunks])

def retrieve(query, k_recall=20, k_final=5):
    qv = enc.encode([query], normalize_embeddings=True)[0]
    scores = vecs @ qv                                  # 向量召回
    vec_rank = np.argsort(-scores)[:k_recall]

    bs = bm25.get_scores(tokenize_zh(query))            # 关键词召回
    kw_rank = np.argsort(-bs)[:k_recall]

    # RRF 融合（k=60 是常用常数）
    fused = {}
    for r, idx in enumerate(vec_rank):
        fused[idx] = fused.get(idx, 0) + 1 / (60 + r)
    for r, idx in enumerate(kw_rank):
        fused[idx] = fused.get(idx, 0) + 1 / (60 + r)
    top = sorted(fused.items(), key=lambda x: -x[1])[:k_recall]

    # 简易重排：用向量分数 + 命中词数做二次打分
    # 生产环境应换成 cross-encoder
    rescored = [(i, fused[i] * 0.6 + float(scores[i]) * 0.4) for i, _ in top]
    rescored.sort(key=lambda x: -x[1])
    return [chunks[i] for i, _ in rescored[:k_final]]
```

**注意 RRF 不需要分数归一化**，这是它比加权求和更好用的原因——两路分数尺度完全不同。

## 14.5 第 4 步：组装与生成

```python
PROMPT = """你是资料助手，只根据下面的材料作答。

材料：
{context}

规则：
1. 每个结论后用 [页码] 标注来源。
2. 材料中没有的内容，直接回答"材料中未找到"。
3. 回答不超过 6 句。

问题：{q}
"""

def answer(q):
    docs = retrieve(q)
    ctx = "\n".join(f"[{d['page']}] {d['text']}" for d in docs)
    return call_llm(PROMPT.format(context=ctx, q=q))   # 调本地或 API
```

**不要忘记"未找到"这条规则**——它能把一部分幻觉转成诚实的拒答。

## 14.6 第 5 步：评估闭环

准备 30 条真实问题，标注"正确页码"。每次改动跑一遍：

```python
def evaluate(qa_set):
    hit, ans_ok = 0, 0
    for item in qa_set:
        docs = retrieve(item["q"])
        if any(d["page"] == item["gold_page"] for d in docs):
            hit += 1
        a = answer(item["q"])
        if item["must_include"] in a:
            ans_ok += 1
    return hit / len(qa_set), ans_ok / len(qa_set)

for cfg in [{"k_final": 3}, {"k_final": 5}, {"k_final": 8}]:
    print(cfg, evaluate(QA))
```

你会得到一条很朴素的曲线：命中率随 k 上升到某个点后不再涨，答案正确率可能反而下降（噪声变多）。**这个拐点就是最优配置**。

## 14.7 第 6 步：升级路径

| 症状 | 升级 |
| --- | --- |
| 表格/公式解析错 | 换结构化解析器，表格单独存 |
| 专有名词查不到 | 加 BM25 权重，或加同义词表 |
| 长文档上下文不够 | 两阶段：先检索段落，再取所在章节 |
| 答案引用错 | 强制引用 + 后处理校验页码存在性 |
| 速度慢 | 嵌入换小模型、缓存 query 向量、生成换量化模型 |
