# 9　生成式 AI 与多模态

生成模型的原理（VAE、GAN、扩散）在卷一第 13 章。这一章讲**产品化的形态**：现在能做什么、用什么控制、卡在哪。

## 9.1 图像生成：可控性比质量更重要

文生图的基本架构是"文本编码器 + 扩散主干 + 解码器"。稳定扩散系列还多一个 VAE，把 512×512 的图压到 64×64 的潜空间再扩散，算力省几十倍。

真正决定可用性的是**控制手段**：

| 手段 | 作用 | 代价 |
| --- | --- | --- |
| 提示词 | 描述内容与风格 | 不稳定，对措辞敏感 |
| 负向提示 | 排除不要的元素 | 需要经验 |
| ControlNet | 用边缘/深度/姿态图约束结构 | 多一次前向，需额外模型 |
| IP-Adapter | 用参考图控制风格/人物 | 需要参考图 |
| LoRA | 定制特定主体或画风 | 需要少量训练数据 |

:::note 要点
"生成质量"很快会同质化，"可控与可编辑"才是产品差异点。做图像产品时，把预算投在控制链路上，比投在换更大的基座模型回报更高。
:::

## 9.2 视频生成：一致性问题

视频比图像多了时间维，难点从"像不像"变成"动不动得对"：

- **时序一致性**：人物的脸、衣服纹理、光照在帧间不能跳变；
- **运动合理性**：物理规律（重力、碰撞）与镜头运动；
- **长视频**：自回归拼接容易漂移，需要关键帧锚定。

当前主流做法是**潜空间扩散 + 时空注意力**（把时间当第三维做注意力），或者用"图像模型 + 运动模块"分离训练。评测仍不成熟，常用人工打分与光流一致性。

## 9.3 语音：三个独立任务

| 任务 | 输入→输出 | 主流方案 | 关键指标 |
| --- | --- | --- | --- |
| ASR（识别） | 音频→文本 | Conformer / Whisper 类 | 字错率 CER |
| TTS（合成） | 文本→音频 | 扩散/流匹配声码器 | MOS 主观分、RTF |
| 声纹/分离 | 音频→身份/干净音轨 | 说话人嵌入、源分离 | 等错误率 EER、SI-SDR |

语音的特殊约束是**实时性**：流式 ASR 要求"边说边出字"，延迟控制在几百毫秒，这与非流式模型的精度有取舍（看未来上下文 vs 只看历史）。

## 9.4 多模态：CLIP 是分水岭

CLIP 用对比学习把图像与文本对齐到同一个向量空间：一批图文对里，配对的为正样本，其余为负样本，损失就是 InfoNCE。

$$ L=-\log\frac{\exp(\mathrm{sim}(I_i,T_i)/\tau)}{\sum_j\exp(\mathrm{sim}(I_i,T_j)/\tau)} $$

它的产物是一个**共享的语义空间**，于是可以做零样本分类（把类别名当文本查询）、图文检索、以及作为视觉编码器接入大模型。

现代视觉语言模型（VLM）的典型结构：

```text
图像 → 视觉编码器（ViT）→ 投影层（MLP/Q-Former）→ 与文本 token 拼接 → LLM 解码
```

关键设计点是**投影层**：它要把视觉特征"翻译"成 LLM 能理解的 token。训练通常分两阶段：先冻结两端只训投影层（对齐），再联合微调（指令跟随）。

## 9.5 多模态的三个真实难点

1. **分辨率与 token 预算**：一张 1024×1024 的图如果切成 16×16 的 patch，就是 4096 个 token，直接吃掉上下文。所以高分辨率需要动态切块 + 压缩；
2. **细粒度 grounding**：模型能描述"图里有一只猫"，但定位"猫的左耳在哪个像素"仍然弱。这需要专门的定位数据与结构（如加检测头）；
3. **视频的时序建模**：帧数 = token 数，成本爆炸。常见折中是低帧率采样 + 关键帧 + 时间位置编码。

## 9.6 选型建议

| 需求 | 建议 |
| --- | --- |
| 商品图、海报、插画 | 扩散 + ControlNet + 固定 LoRA |
| 需要精确文字渲染 | 专门优化的模型（文字渲染一直是弱项） |
| 短视频素材 | 图生视频（首帧可控）优于纯文生视频 |
| 语音转写 | 开源 Whisper 类 + 领域词表微调 |
| 图文检索 | CLIP 类双塔，领域数据上微调 |
| 图文问答 | 开源 VLM 微调，或调用 API |

:::warn 常见坑
- 直接用通用文生图做品牌素材，会出现 Logo 变形、文字乱码——必须用参考图约束（IP-Adapter）或后期合成；
- 语音合成的评测 MOS 分需要人听，自动化指标（如 MCD）与主观感受相关性有限；
- 多模态模型的"看图说话"能力很强，但"按坐标定位"能力弱，不要用它替代检测模型。
:::
