# 1　六十年：三次浪潮与两次寒冬

了解历史不是为了背年份，而是为了看清一件事：**这个领域每隔十几年就会重演一次"能力被高估、然后被现实打回"的循环**。知道这个模式，你对当下任何"颠覆性突破"的判断都会更冷静。

| 时期 | 主线 | 代表成果 | 为什么会结束 |
| --- | --- | --- | --- |
| 1943–1956 | 神经元模型与图灵测试 | McCulloch-Pitts 神经元、感知机 | 单层感知机无法解决异或，被证明能力有限 |
| 1956–1974 | 符号主义与搜索 | 通用问题求解器、LISP | 组合爆炸、常识难以手工编码 |
| 1974–1980 | 第一次寒冬 | 经费收缩 | 承诺与现实差距过大 |
| 1980–1987 | 专家系统 | 医疗诊断、配置系统 | 规则维护成本爆炸，无法处理不确定性 |
| 1987–1993 | 第二次寒冬 | — | 专家系统泡沫破裂 |
| 1986–2011 | 统计学习 | 反向传播、SVM、随机森林、CRF | 特征工程瓶颈、数据规模受限 |
| 2012–2017 | 深度学习 | AlexNet、ResNet、seq2seq、GAN | 需要大量标注，泛化到新任务成本高 |
| 2017–2022 | 预训练 + 微调 | Transformer、BERT、GPT | 每任务一模型，部署与维护成本高 |
| 2022–至今 | 大模型与多模态 | 指令微调、RLHF、扩散、Agent | 推理成本、可靠性、幻觉仍未解决 |

## 1.1　三次浪潮共同的形状

每一轮都遵循同一个剧本：

1. **一个新方法解决了旧方法的瓶颈**（感知机解决手工规则，深度学习解决特征工程，大模型解决任务定制）；
2. **媒体与资本把"能做什么"外推成"什么都能做"**；
3. **真实场景的边界条件（数据、成本、可靠性）暴露**；
4. **进入低谷，但方法本身沉淀下来**。

低谷期并非浪费：SVM、集成学习、概率图模型都是在寒冬前后成熟的，它们至今是表格数据与可解释场景的主力。

## 1.2　两次真正的转折点

如果只能记两个节点，记这两个：

- **2012 年 AlexNet**：GPU + ReLU + Dropout + 大数据，把 ImageNet 错误率从 26% 拉到 15%。它证明的不是"卷积好用"（卷积早就好用），而是**"算力 + 数据"能突破手工特征的天花板**；
- **2017 年 Transformer**：把序列建模从串行改成并行，使"堆更多层、喂更多数据"在工程上可行。它之后的每一年，模型规模与数据规模都在按同一条曲线增长。

## 1.3　当前阶段的三个真实约束

历史告诉我们，判断一个技术能否落地，看三件事是否同时成立：

| 约束 | 现状 | 影响 |
| --- | --- | --- |
| 数据 | 文本、图像充裕；专业领域稀缺 | 通用能力易得，专业能力仍需标注 |
| 算力 | 训练集中在大厂，推理可下沉 | 本地部署以量化为前提 |
| 可靠性 | 幻觉、分布外失效仍普遍 | 高风险场景必须人在回路 |

**结论：通用能力已经"过剩"，稀缺的是可靠性与领域数据。** 这也是为什么近几年的技术热点集中在 RAG、Agent、评测、对齐——它们都在补"可靠性"这一块。

:::note 要点
看到"某模型又突破"时，先问三个问题：它在什么数据上评的？失败模式是什么？单位成本多少？这三问能过滤掉大部分噪音。
:::
