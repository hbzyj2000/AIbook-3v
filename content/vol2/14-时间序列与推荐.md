# 13　时间序列与推荐系统

这两类任务承担了 AI 商业化的大部分收入，但它们的核心方法往往不是深度网络，而是**特征工程 + 树模型 + 业务规则**。理解这一点，能避免"什么都上大模型"的浪费。

## 13.1 时间序列：先分解，再选模型

任何时间序列都可以尝试分解成三部分：

$$ y_t = T_t + S_t + R_t $$

趋势（$T$）、季节（$S$）、残差（$R$）。分解之后你会立刻知道：这条曲线是"整体在涨"还是"周期性波动"，两者的建模方式完全不同。

| 数据特征 | 推荐方法 |
| --- | --- |
| 短序列、强季节、单变量 | 指数平滑（ETS）、Prophet |
| 平稳、有自相关 | ARIMA / SARIMA |
| 多变量、有外生变量 | 梯度提升树 + 滞后特征 |
| 超长序列、大规模 | 深度模型（TCN、Transformer 变体） |
| 不确定性要量化 | 分位数回归、概率预测 |

**实践中的第一名往往不是 ARIMA 也不是 Transformer，而是"滞后特征 + LightGBM"**：把 $y_{t-1},y_{t-2},\dots$ 与日期特征、外生变量拼成表，当回归问题做。原因是它对缺失值、异常值、多变量交互的处理远比经典时序模型稳健。

## 13.2 时序任务的四个陷阱

1. **数据泄漏**：用未来信息算特征（如用全期均值做标准化）会让离线指标虚高，线上崩盘；
2. **切分方式错**：时序数据不能随机划分，必须按时间切（训练用前 70%，验证用后 30%）；
3. **评估指标错**：MAPE 在接近 0 的值上爆炸，用 sMAPE 或 MASE 更稳；
4. **忽视节假日与促销**：这些"异常"是业务的主要波动源，必须显式建模。

## 13.3 推荐系统：三段式结构

```text
召回（万级 → 千级）  →  粗排（千级 → 百级）  →  精排（百级 → 十级）
```

| 阶段 | 目标 | 常用方法 |
| --- | --- | --- |
| 召回 | 快速筛出可能相关的候选 | 协同过滤、双塔向量检索、热门/规则 |
| 粗排 | 低成本排序 | 小型模型、特征交叉 |
| 精排 | 精确预估点击/转化率 | 深度模型（DIN、DeepFM） |

**召回决定了天花板**：精排再强，召回没捞到的物品永远不可能被推荐。所以工业界的功夫大量花在召回的多路并行上（协同、向量、热门、社交、地域各一路）。

## 13.4 协同过滤的两种形态

- **基于用户**：找相似用户，推荐他们喜欢的；
- **基于物品**：找相似物品，推荐与当前物品相似的。

核心是相似度矩阵。用矩阵分解（SVD/ALS）可以把 $m\times n$ 的稀疏评分矩阵压成两个低秩矩阵：

$$ R\approx P Q^{\top},\qquad P\in\mathbb{R}^{m\times k},\ Q\in\mathbb{R}^{n\times k} $$

这和第 14 章（卷一）的隐语义模型是同一件事。

## 13.5 双塔模型：召回的现代主力

用户塔编码用户特征，物品塔编码物品特征，两边输出向量后做内积：

$$ \text{score}(u,i)=\langle f_u(u),f_i(i)\rangle $$

关键优势：**物品向量可以离线预计算并建索引**，线上只需算用户向量再做近邻检索，毫秒级响应。

训练用负采样 + softmax（in-batch negative 是标配）。注意**样本偏差**：曝光过的物品才有标签，未曝光的不代表不相关。常用纠偏手段是加上曝光概率的倒数加权。

## 13.6 冷启动：三类解法

| 类型 | 问题 | 解法 |
| --- | --- | --- |
| 新用户 | 没有行为 | 用注册信息 + 热门 + 探索策略 |
| 新物品 | 没有交互 | 用内容特征做向量（图文嵌入） |
| 新场景 | 没有数据 | 迁移已有模型 + 人工规则兜底 |

**探索与利用的平衡（EE 问题）**是冷启动的理论核心：多探索能发现好内容，但短期指标会掉。常用 Bandit 算法（UCB、Thompson Sampling）来量化这个权衡。

## 13.7 评估：离线指标与线上指标经常背离

| 离线 | 线上 |
| --- | --- |
| AUC、NDCG、Recall@k | 点击率、转化率、时长、留存 |

背离的三个原因：离线用的是历史曝光数据（有偏）、离线不看多样性（线上会审美疲劳）、离线不看实时性（线上要求毫秒级）。

**结论：离线指标只用来筛方案，最终判断必须靠线上 A/B。**

:::note 要点
这两类任务的共同特征是**特征比模型重要、评估比训练重要**。如果你有时间，先做特征工程与数据质量，再考虑换模型。
:::
