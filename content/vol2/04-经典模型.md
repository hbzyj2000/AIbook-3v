# 3　经典模型：能不用深度就不用

这一章不推导（推导在卷一第 6–9 章），只给**选型判断**。理由很简单：经典模型训练快、可解释、部署轻、对数据量要求低，在很多真实业务里它已经够用，而深度模型带来的额外复杂度需要实打实的收益来换。

## 3.1　选型速查

| 场景 | 首选 | 备选 | 关键理由 |
| --- | --- | --- | --- |
| 需要解释每个预测 | 逻辑回归 + 特征工程 | 浅层树 + SHAP | 系数可直接解释 |
| 表格数据、追求精度 | LightGBM / XGBoost | CatBoost | 抗尺度、抗缺失、自动交互 |
| 样本极少（<1000） | 逻辑回归 / 朴素贝叶斯 | 核 SVM | 参数少，不容易过拟合 |
| 高维稀疏（文本 TF-IDF） | 线性 SVM / 逻辑回归 | 朴素贝叶斯 | 高效、稳定 |
| 需要概率校准 | 逻辑回归 / 校准后的树 | Platt scaling | 树输出的概率不平滑 |
| 在线学习、流式更新 | SGDClassifier / 被动攻击 | — | 支持增量 |
| 异常检测、无标签 | 孤立森林 / LOF | 自编码器重构误差 | 无需标签 |
| 时序预测、强季节性 | 季节性 ARIMA / Prophet | LightGBM + 时间特征 | 树不能外推趋势 |
| 中小规模图像 | 预训练 CNN 微调 | HOG+SVM | 迁移学习远胜手工特征 |

## 3.2　线性模型的价值：可解释与可校准

逻辑回归的系数 $\beta_j$ 表示"特征 $x_j$ 增加一单位，对数几率增加 $\beta_j$"。这是业务方唯一能直接读懂的形式，也是风控、医疗、金融等受监管行业仍大量使用它的原因。

两点工程经验：

- **先做特征标准化**，否则系数大小不可比（正则化也会失真）；
- **注意多重共线性**：两个高度相关的特征会让系数符号翻转，解释失真。用 VIF 检查，或改用岭回归。

## 3.3　树集成：表格数据的事实标准

LightGBM 在中等数据上通常是最强基线，配置建议：

```python
import lightgbm as lgb

params = dict(
    objective='binary',
    learning_rate=0.05,        # 先小一点，配合更多轮
    num_leaves=31,             # 控制复杂度，别超过 2^depth
    min_data_in_leaf=20,       # 防过拟合的关键参数
    feature_fraction=0.8,      # 列采样，降相关性
    bagging_fraction=0.8,
    bagging_freq=1,
    lambda_l2=1.0,             # 叶权重正则
    metric='auc',
)
# 早停：验证集连续 50 轮不提升就停
model = lgb.train(params, dtrain, num_boost_round=2000,
                  valid_sets=[dvalid], callbacks=[lgb.early_stopping(50)])
```

调参优先级（按收益排序）：`learning_rate` + `num_boost_round` 一起调 → `num_leaves` / `min_data_in_leaf` → 采样比例 → 正则项。

**不要做的事**：把连续特征做标准化（树不在乎）、对缺失值做插补（LightGBM 原生处理更好）、做大量多项式特征（树自己会组合）。

## 3.4　核 SVM：小样本高维的可靠选择

适用条件很明确：**样本量几千以内、特征维度高、边界非线性但类别可分**。文本分类（TF-IDF 特征）是它的经典战场。

三个必调项：$C$（正则强度）、核类型、RBF 的 $\gamma$。经验起点：$C$ 从 1 开始按 10 倍网格搜索，$\gamma$ 取 $1/d$（$d$ 是特征数）附近。

**不适用的场合**：样本超过 5 万（训练 $O(N^3)$）、需要输出概率（要用 Platt 校准，成本不低）、需要在线更新。

## 3.5　KNN 与朴素贝叶斯：简单但边界清晰

**KNN** 没有训练阶段，预测时算距离。它的隐含假设是"近处样本同类"。高维时距离会失效（维度灾难：所有点对的距离趋于相同），必须先降维或选特征。适合作为"必须极简"场景的兜底。

**朴素贝叶斯** 假设特征在给定类别下条件独立。这个假设几乎总是错的，但它在文本分类上仍然有效——因为分类只需要"哪个后验最大"，不需要概率精确。它的优点是训练是闭式解、极快、可增量。

## 3.6　可解释性：三种工具

| 工具 | 说明 | 适用 |
| --- | --- | --- |
| 特征重要性（分裂增益） | 树模型自带，反映"用了多少" | 快速筛查，但有偏（偏好高基数特征） |
| Permutation importance | 打乱某特征看指标掉多少 | 更可靠，计算成本高 |
| SHAP | 基于博弈论的边际贡献分配 | 单样本解释，可加性严格 |

SHAP 值得多用：它给出"这个样本为什么被判为高风险"的逐特征归因，业务方能接受，也便于发现数据 bug（比如某个 ID 类特征贡献异常高，往往是泄漏）。
