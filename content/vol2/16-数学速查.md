# 15　数学速查：读论文时最常翻的几页

这一章不做推导，只做**索引**。推导在卷一。遇到符号看不懂时，先来这里找。

## 15.1 矩阵求导常用式

分子布局约定（$y$ 为标量，$x$ 为向量，$A$ 为矩阵）：

| 表达式 | 结果 |
| --- | --- |
| $y=a^{\top}x$ | $\partial y/\partial x=a$ |
| $y=x^{\top}Ax$ | $\partial y/\partial x=(A+A^{\top})x$，$A$ 对称时为 $2Ax$ |
| $y=\|x\|_2^2$ | $2x$ |
| $y=\|Ax-b\|_2^2$ | $2A^{\top}(Ax-b)$ |
| $y=\log\det A$ | $A^{-\top}$ |
| $y=\mathrm{tr}(AB)$ | $\partial y/\partial A=B^{\top}$ |

**记住这条**：$\nabla_x\|Ax-b\|^2=2A^{\top}(Ax-b)$。它与最小二乘的正正规方程 $A^{\top}Ax=A^{\top}b$ 是同一件事。

## 15.2 概率分布速查

| 分布 | 用途 | 均值 / 方差 |
| --- | --- | --- |
| 伯努利$(p)$ | 二分类标签 | $p$ / $p(1-p)$ |
| 分类$(p_1..p_k)$ | 多分类 | 交叉熵的来源 |
| 高斯$\mathcal{N}(\mu,\sigma^2)$ | 连续值、重参数化 | $\mu$ / $\sigma^2$ |
| 拉普拉斯 | L1 正则的对应分布 | 尖峰厚尾 |
| 狄利克雷 | 概率单纯形上的分布 | 主题模型的先验 |
| 泊松 | 计数数据 | $\lambda$ / $\lambda$ |

**关键联系**：损失函数都有对应的概率解释。MSE ↔ 高斯似然，交叉熵 ↔ 分类似然，L1 ↔ 拉普拉斯先验。看到损失就能反推假设。

## 15.3 常用不等式

| 不等式 | 形式 | 用途 |
| --- | --- | --- |
| 詹森 | $f(\mathbb{E}X)\le\mathbb{E}f(X)$（$f$ 凸） | 变分下界、EM 推导 |
| 柯西-施瓦茨 | $\|\langle x,y\rangle\|^2\le\|x\|^2\|y\|^2$ | 相似度上界 |
| 三角不等式 | $\|x+y\|\le\|x\|+\|y\|$ | 距离性质 |
| 切比雪夫 | $P(\|X-\mu\|\ge k\sigma)\le1/k^2$ | 集中不等式 |
| Hoeffding | 有界变量的偏差指数衰减 | 泛化界 |
| 数据处理不等式 | $I(X;Z)\ge I(X;Y)$（$X\to Y\to Z$） | 证明特征不会增加信息 |

数据处理不等式值得单独理解：**任何处理都只会减少信息，不会增加**。这解释了为什么"更好的预处理"能提效（保留任务相关信息），但不能凭空造出信息。

## 15.4 信息论四个量

$$ H(X)=-\sum p\log p,\quad H(X|Y)=H(X,Y)-H(Y) $$

$$ I(X;Y)=H(X)-H(X|Y)=H(X)+H(Y)-H(X,Y) $$

$$ D_{\mathrm{KL}}(p\|q)=\sum p\log\frac{p}{q} $$

$$ \mathrm{JS}(p\|q)=\tfrac12 D(p\|m)+\tfrac12 D(q\|m),\quad m=\tfrac{p+q}{2} $$

三个必须记住的性质：

- **KL 不对称**：$D(p\|q)\ne D(q\|p)$，所以它不是距离；
- **KL 非负**，当且仅当两分布相同为 0（由 Jensen 得到）；
- **互信息对称**：$I(X;Y)=I(Y;X)$，而 KL 不对称。

## 15.5 优化里的几个关键词

| 词 | 含义 | 典型场景 |
| --- | --- | --- |
| 凸函数 | 局部最优即全局最优 | 逻辑回归、SVM |
| 强凸 | 收敛速度有保证 | 岭回归 |
| Lipschitz 连续 | 梯度变化有上界 | 梯度裁剪的依据 |
| 鞍点 | 梯度为 0 但非极值 | 深层网络、GAN |
| 条件数 | 最大/最小特征值之比 | 决定梯度下降快慢 |

**条件数**常被忽略：它决定了损失曲面的"狭长程度"。条件数大的问题，梯度下降会震荡，这就是为什么需要归一化与自适应优化器。

## 15.6 复杂度速查

| 操作 | 时间 | 空间 |
| --- | --- | --- |
| 矩阵乘 $(m\times k)(k\times n)$ | $O(mkn)$ | $O(mn)$ |
| 求逆 $n\times n$ | $O(n^3)$ | $O(n^2)$ |
| 自注意力（序列 $T$，维度 $d$） | $O(T^2d)$ | $O(T^2)$（未融合） |
| 卷积（核 $k$，通道 $C$，输出 $H\times W$） | $O(HWk^2C^2)$ | — |
| 排序 $n$ 个元素 | $O(n\log n)$ | — |
| 近邻检索（HNSW） | 约 $O(\log n)$ | $O(nM)$ |

:::note 用法
读论文卡住时，先确认三件事：**符号的布局约定、张量的形状、复杂度里的主导项**。这三件事清楚之后，大部分推导都能跟上。
:::
